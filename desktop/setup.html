Σύνδεσε μία φορά αυτή την εγκατάσταση με το ίδιο Supabase project της online έκδοσης. Μετά θα ανοίγεις μόνο το MyFinHub shortcut — χωρίς browser, terminal ή Vercel.

Τι εκτελείται στο παρασκήνιο
  • Πραγματικός έλεγχος HTTPS Supabase URL και publishable key
  • Αποθήκευση public config στον Windows λογαριασμό
  • Κρυπτογράφηση card-vault key με Windows DPAPI, αν δόθηκε
  • Εκκίνηση του bundled Node.js 22 local backend στο 127.0.0.1
  • Άνοιγμα του MyFinHub στο δικό του desktop παράθυρο

    
Αν κάτι αποτύχει, η οθόνη παραμένει ανοιχτή για διόρθωση και νέα προσπάθεια. Τα διαγνωστικά περιορίζονται σε στάδιο, κωδικό και ασφαλές τεχνικό detail: Supabase keys, tokens, card-vault key και οικονομικά δεδομένα δεν εμφανίζονται. Το card-vault key αποθηκεύεται κρυπτογραφημένο μέσω Windows-backed Electron safeStorage/DPAPI.
