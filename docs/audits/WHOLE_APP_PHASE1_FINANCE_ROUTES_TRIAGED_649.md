## New material cross-page defect CARD-649-01 — approved 32-digit PAN contract blocked by current card editor

**Source + durable owner contract — A / P1 functional/security-sensitive UI.** Issue #266's approved 2026-10-26 in-place card editing decision explicitly says **“32-digit PAN support” must be preserved**, with mandatory authorized server-side vault and WYSIWYG physical-card editing. However current:
- `src/lib/cardDetails.ts::formatCardNumberInput` slices input to **16** digits, `normalizeCardDetailsInput` requires `/^\d{16}$/`, rejects non-16 new writes.
- `src/components/CardDetailsDialog.tsx` secure card PAN inputs have **`maxLength={19}`**, and the helper text says **16 digits / 4×4**.
- The same CardDetails component is used by debit/prepaid and credit secure detail editing; the card UI has a *read-only legacy* long-PAN two-line presentation if an old stored value is already longer. A **legacy display fallback does not satisfy new/editable 32-digit persistence**.
- `tests/card-details.test.ts` explicitly asserts rejection of non-16 values, so the existing source test currently **enforces a product-contract mismatch**, rather than guarding the approved 32-digit capability.
- `server/cardVaultStore.ts` references the “new 16/expiry/3 write contract” and accepts legacy values selectively. This is a **cross-component and server contract** concern; not just raising input `maxLength`.

**Phase 2 acceptance:** one shared, security-reviewed PAN input/format/validation/vault contract across Cards and Credit; support explicitly authorized 16 and **32-digit** typed/pasted/edit values, preserve PAN metadata redaction, secret isolation and server encryption, prohibit string truncation, provide exact protected submit/reload test and physical WYSIWYG card ratio/toolbar/effective-layout at 320/375/1440. Update the old conflicting tests in favor of accepted owner behavior; no unapproved card-secret migration, production reveal or copying PAN to logs. This finding must not be hidden as visual polish or merged alone as a micro PR.
