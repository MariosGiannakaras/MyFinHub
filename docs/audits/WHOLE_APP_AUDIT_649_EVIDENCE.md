## 6. What constitutes an actionable result
- **Confirmed A:** fix the owning cause and add a focused regression guard; verify siblings and all relevant rendered states.
- **Candidate B:** first reproduce with DOM/effective CSS/event trace/fixture; only patch if actual defect established. Otherwise record tested-no-defect and remove/replace scoped item in plan with transparent denominator adjustment.
- **UX C:** present precise accepted contract or ask the owner only if genuinely incompatible requirements require a product decision. Avoid cosmetic surgery while finance/security work is unaccepted.
- **Safety S:** preserve boundaries, run non-mutating evaluation/negative tests, propose reviewed migration/config or protected isolated recovery test. An advisor warning cannot itself authorize production policy change.
- **Already correct D:** preserve and reuse regression lock; do not reopen old completed work or rewrite established finance history.
