# MyFinHub approved page patterns

Status: **bootstrap — no new redesign patterns approved yet**.

This file records reusable structural patterns only after they are established by an owner-approved redesign. Do not treat a one-off arrangement as a shared pattern merely because it exists on one page.

## Candidate pattern registry

The following areas are expected to emerge during the redesign but are not yet approved contracts:

- application shell / desktop navigation;
- standard page header;
- financial summary strip;
- account summary;
- filter/search toolbar;
- dense transaction/data table;
- responsive-safe data list (regression support only in Phase 1, not mobile visual redesign);
- form section / Quick Entry grouping;
- detail/history section;
- chart/insight section;
- status/attention item;
- settings group;
- empty/loading/error state;
- modal/drawer/popover composition.

## Pattern entry format

When a pattern is actually approved, record:

- **Name**
- **Established by**: approved surface/reference path
- **Purpose**
- **Required structure/behavior**
- **Allowed variation**
- **Do not use when**
- **Implementation components/tokens** once Chat B has implemented them

Prefer evolving an existing shared pattern when a later surface reveals a broader requirement instead of creating a visually competing one-off variant.
