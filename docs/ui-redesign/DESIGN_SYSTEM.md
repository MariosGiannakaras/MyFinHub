# MyFinHub desktop redesign system

Status: **bootstrap — intentionally minimal**.

Do not invent a complete token system before the owner approves real redesigns. This file records durable shared decisions only after they are established through approved surfaces.

## Existing non-negotiable quality baseline

The redesign must preserve the accessibility/interaction requirements in `docs/UX_STANDARDS.md`, including strong contrast, visible focus/boundaries, explicit control states, reduced-motion support and appropriate dense-data patterns.

## Direction established at bootstrap

- Product: MyFinHub, personal-finance application.
- Phase: desktop web/Windows-rendered UI only.
- Quality direction: clean, modern, premium, trustworthy, calm, professional and data-friendly.
- Avoid generic AI-dashboard styling, gratuitous glassmorphism/gradients, excessive shadows, oversized cards/typography, decorative noise and unnecessary whitespace.
- Cards are grouping tools, not the default container for every datum.
- Financial information hierarchy and scanning efficiency take priority over decoration.
- `references/direction/dashboard-new-direction.webp` is a quality/design-language reference, not a rigid composition template.
