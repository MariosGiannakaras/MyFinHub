# Approved desktop redesign targets

Only an image explicitly approved by the owner belongs here.

Canonical structure:

```text
references/approved/<surface>/desktop.png
```

Rules:

- Phase 1 stores desktop targets only.
- Do not commit rejected drafts or `final-v2-final` style filenames.
- When a later approved revision replaces a target, replace `desktop.png`; Git history preserves the previous version.
- The exact approved image is authoritative for presentation of that surface, subject to `PROJECT_SCOPE.md` source-of-truth precedence.
- Do not regenerate an approved image merely to persist it. Persist the exact approved asset.
