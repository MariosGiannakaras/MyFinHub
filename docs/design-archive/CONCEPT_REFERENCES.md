## Current interpretation

- `OLD DESIGN.png` is historical context only.
- `NEW REDISIGN.png` remains a useful quality-direction reference for hierarchy, density and financial information presentation.
- Neither image overrides current product semantics, accessibility requirements, responsive behavior or explicit owner decisions.
- The post-v1.3 visual direction intentionally moves away from heavy neumorphic/soft-embossed treatment toward flatter premium-fintech surfaces, restrained elevation, clearer hierarchy and centralized design tokens/primitives.

## Archive rule

Concept/reference images must remain separate from `visual-qa/final/**`. The latter is implementation evidence; this archive is design provenance.
